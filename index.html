02 Algorithm

The Direction-Aware LOOK Algorithm

Naive dispatchers only calculate absolute distance (`|f - S|`), causing erratic direction switching and starvation. The LOOK algorithm accounts for current motion and travel direction.

01

Approaching in Same Direction (Golden Path)

When an elevator is traveling towards the passenger floor and the passenger wants to move in that identical direction, the passenger is boarded along the current sweep with minimal delay (Cost: |S - f|).

02

Approaching in Opposite Direction

If the elevator is cruising towards the passenger but the passenger wants to ride in reverse, the car finishes its sweep to the top/bottom floor before returning to pick up the rider.

03

Passed Floor (Turnaround Penalty)

If the car has already ascended or descended past the passenger, it must complete its full trip and reverse, receiving a heavy distance penalty so other idle cars are preferred.

03 Architecture

Strict Object-Oriented C++ Design

Engineered with industry-standard C++17 object-oriented design patterns, high cohesion, low coupling, and zero abstraction leaks.

STRUCTURAL

Nested Class

ElevatorMotor is declared privately inside Elevator to encapsulate horsepower and operational state from external classes.

class Elevator {
  class ElevatorMotor {
    void start(); void stop();
  };
};
INHERITANCE

Final Derived Class

EmergencyElevator inherits from Elevator and is marked with the final keyword to restrict unauthorized subclassing.

class EmergencyElevator final
  : public Elevator {
  string sirenCode;
};
POLYMORPHISM

Runtime Polymorphism

Base class pointer Elevator* triggers dynamic dispatch via virtual move() and override display() methods.

virtual void display() const;
void display() const override;
OPERATOR

Stream Overloading

Overloaded operator<< via friend functions allows direct object streaming to std::cout without getters.

friend ostream& operator<<(
  ostream& os, const Elevator& e
);
OPERATOR

Equality Operator

Overloaded operator== on ElevatorRequest facilitates instant comparison of duplicate trips across queue queues.

bool operator==(
  const ElevatorRequest& other
) const;
STATIC

Static Analytics

totalRequests and getTotalRequests() maintain a class-level counter of all elevator journeys across the tower.

static int totalRequests;
static int getTotalRequests();
